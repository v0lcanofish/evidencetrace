# 一、逐源实测结果

| 数据源 | 可达 | 引用 ID | 结构化 | 语言 | 判定 |
|---|---|---|---|---|---|
| **NMPA 主站** | ❌ **HTTP 412** | — | — | 中文 | **不可用** |
| NMPA 数据共享平台 | ❌ **HTTP 412** | — | — | 中文 | **不可用** |
| NMPA 信息中心 nmpaic | ✅ 200 | — | ⚠️ 目录页 | 中文 | 待深挖 |
| **DailyMed（美国 NLM）** | ✅ **API 可用** | **`setid`** | ✅ **SPL/HL7，章节带 LOINC 码** | 英文 | ⭐ **最佳** |
| openFDA | ✅ API 可用 | NDA/ANDA | ✅ | 英文 | 备选 |

| flk.npc.gov.cn（法规） | ⚠️ **SPA，返回 HTML** | — | — | 中文 | 需逆向 |

## NMPA 为什么拿不到

```
https://www.nmpa.gov.cn/                      → HTTP 412 Precondition Failed
https://zhjg.nmpa.gov.cn/datacatalog/dataset  → HTTP 412 Precondition Failed
（加了完整浏览器请求头 + Accept-Language 后仍然 412）
```

**412 是 WAF/JS challenge**，不是缺 header。要绕需要逆向或浏览器自动化——**成本高、稳定性差，不适合做研究语料**。

## DailyMed 为什么更好

实测三个接口全通：

```
① 药品名列表（可翻页，批量用）
   GET /dailymed/services/v2/drugnames.json?pagesize=100&page=1
   → 100 条/页，metadata 里有 next_page_url

② 按药名查说明书
   GET /dailymed/services/v2/spls.json?drug_name=ibuprofen&pagesize=1
   → {"setid": "5a709591-2fab-98e7-e063-6394a90ac50a", "title": "...", "published_date": "Sep 15, 2026"}
   （ibuprofen / amoxicillin / metformin / warfarin 全部有结果）

③ 取单份说明书全文（SPL XML）
   GET /dailymed/services/v2/spls/{setid}.xml
   → 26 KB，HL7 SPL 标准格式，含 <setId> 与 <section>
```

### ⭐ 它比 NMPA 强在哪

| | NMPA | **DailyMed** |
|---|---|---|
| 唯一 ID | 批准文号（国药准字） | **`setid`（UUID）** |
| 章节 | 文本标题（【禁忌】） | **LOINC 编码**（结构化的，机械可判） |
| 获取 | ❌ 反爬 | ✅ **公开 API，无需认证** |
| 批量 | 难 | ✅ **有分页** |

> ⭐ **LOINC 章节码意味着「该引哪一节」是机械可判的** ——
> 比中文说明书的【禁忌】文本标题更硬，**gold 证据集可以半自动构造**。

# 二、⚠️ 场景决策点

**原定场景"医药电商用药咨询"用的是中文说明书（NMPA）—— 这个前提不成立了。**

## 三个选项

| | 方案 A（推荐） | 方案 B | 方案 C |
|---|---|---|---|
| **语料** | **DailyMed 英文药品说明书** | 法规（需逆向 flk） | 天池中药说明书 1997 份 |
| **场景** | 跨境/海外药品咨询、出海药企 | 企业合规问答 | 中药用药咨询 |
| **数据** | ✅ **完美** | 🟡 要解决 API | 🟡 量少 |
| **引用 ID** | ✅ **setid + LOINC** | ✅ 法条编号 | 🟡 需自定 |
| **业务说服力** | 🟡 英文场景略弱 | ✅ 强 | ✅ 强 |
| **改成中文？** | ❌ | ✅ | ✅ |

## ⭐ 推荐方案 A，理由

1. **数据质量压倒性优势**：唯一 ID + LOINC 章节码 + 公开 API + 可批量
2. **引用可验证率在这里更强**：`setid` 存在性 + **LOINC 章节码是否真的是那一节** —— 双重可核验
3. **gold 可半自动构造**：LOINC 码直接告诉你"回答这个问题必须引哪几节"
4. **场景仍成立**：**跨境医药电商 / 出海药企的药品信息问答** —— 中国药企出海是真实且火热的业务
5. **技术点完全不变**：账本、三层归因、引用可验证率、中文 BM25（改成英文 BM25，反而和 ToolHorizon 复用度更高）

## 方案 A 的代价（诚实说）

- ⚠️ **语言从中文变英文**：少了"中文分词/中文语料"这个亮点
- ⚠️ "医药电商"的业务感弱一点（但要讲成"跨境"就成立）
